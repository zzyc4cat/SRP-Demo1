## 技术栈

| 层 | 技术 |
|----|------|
| 造型 | Shell Texturing。同一网格沿法线挤出多层，层号用 `_LayerRatio`（0 在皮上，1 在毛尖） |
| 绘制 | `Graphics.DrawMeshInstanced`。一层一个实例，`_LayerRatio` 放在 Instancing 属性块里 |
| LOD | 按相机距离在 `maxShellCount` 和 `minShellCount` 之间减层 |
| 形变 | 挤出后加重力、Comb 梳理方向和风力。风力用 MaterialPropertyBlock 的 `_WindVector`，不进 PerMaterial 常量缓冲 |
| 镂空 | 噪声贴图。根部阈值低、毛尖阈值高，所以根密梢疏 |
| 颜色 | 根色到梢色按层插值，加一点主光高光 |
| 深度 | Forward 和 DepthOnly 共用 `FurCommon` 的顶点形变。DepthOnly 的 `ColorMask` 默认不写颜色，用来做 Early-Z |
| 数值 | `FurSafePow` 避免负底数 `pow` |

`UniversalForward` 必须是 Pass 0。部分 `DrawMeshInstanced` 路径只认第一个 Pass，若深度 Pass 排在前面，毛发会只写深度、没有颜色。

## 数据流

```
CPU：按距离决定层数 → 填每层矩阵和 _LayerRatio → DrawMeshInstanced
GPU：挤出 + 重力 + 梳理 + 风 → 噪声裁掉毛尖以外的像素 → 根梢上色
     DepthOnly 用同一套形变先写深度
```

材质需要勾选 Enable GPU Instancing。

## 取舍

| 优点 | 限制 |
|------|------|
| 一张网格出短毛，层数可按距离降 | 层数直接乘填充率 |
| DepthOnly 减少壳层互相重绘 | 不是单根毛发，也没有毛发碰撞 |
