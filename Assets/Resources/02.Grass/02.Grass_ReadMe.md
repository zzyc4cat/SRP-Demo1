## 技术栈

| 阶段 | 技术 |
|------|------|
| 细分 | Hull / Domain。`_TessellationUniform` 做均匀细分，提高草根密度 |
| 几何 | Geometry Shader。每个细分三角形挤出一片草：底边两点加梢部一点 |
| 朝向 | 以三角首顶点为根，建 TBN。随机绕法线旋转，再按 `_BendRotationRandom` 前倾 |
| 风 | 世界 XZ 采样 `_WindDistortionMap`，UV 按 `_WindFrequency` 滚动。梢部用 Rodrigues 旋转 |
| 压草 | `_Players` 数组找最近角色。进入半径后绕垂直轴把梢部压向外侧 |
| 着色 | 根 `_BottomColor`，梢 `_TopColor`。`VFACE` 翻法线。`NdotL` 加 `_TranslucentGain` 做透光，再乘主光阴影和环境光 |
| 阴影 | ShadowCaster Pass 只写深度，`ColorMask` 默认不输出颜色 |
| 平台 | `#pragma target 4.6`，需要 geometry 和 tessellation。排除 GLES、Metal 等没有这些阶段的后端 |

角色位置由 `GetPlayerPos` 写入材质，`GrassCollider` 提供压草半径。交互人数上限由 `GRASS_MAX_PLAYERS` 决定（100）。

## 数据流

```
地面网格
  → 细分加密草根
  → 几何着色器生成叶片（根只跟朝向，梢叠加弯曲、风、压草）
  → 片元：根梢渐变 × 透光 × 阴影
  → 阴影 Pass：同样的叶片形状，只写深度
```

## 取舍

| 优点 | 限制 |
|------|------|
| 一块网格覆盖大面积草 | 依赖桌面级几何管线 |
| 风和压草在 GPU，不逐片回读 | 密度上去后细分和几何着色器开销大 |
| 远近都是同一套叶片逻辑 | 不是单根毛发或网格实例草 |
