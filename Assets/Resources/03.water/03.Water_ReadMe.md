## 技术栈

| 阶段 | 技术 |
|------|------|
| 波浪 | 多条 Gerstner 叠加。水平位移用余弦，垂直位移用正弦。GPU 读 StructuredBuffer 或向量数组，公式在 `GerstnerWaves.hlsl` |
| 网格 | 相机前方分块铺海面，水平位置按固定间距对齐，避免接缝跟着镜头抖 |
| 浅水 | 正交相机拍岸边深度。水浅处减小水平位移，并抬高顶点，避免浪穿进岸里 |
| 水色 | 128×4 的颜色 ramp：吸收、散射、泡沫密度 |
| 反射 | Cubemap、反射探针、平面反射三选一。本场景用平面反射：镜像相机加斜裁剪近平面 |
| 折射 | 采样不透明颜色，用法线偏移 UV，再按水深乘吸收色 |
| 泡沫 | 浪尖、岸线、以及 WaterFX 的 R 通道。泡沫贴图 RGB 对应厚、中、薄 |
| 焦散 | 天空之后画一块大平面。用深度还原水下位置，沿主光方向采样两层噪声，以 `DstColor` 相乘到水底 |
| 局部扰动 | WaterFX 半分辨率图：R 泡沫，GB 法线，A 位移。当前场景没有物体画这条 Pass |
| 植被 / 悬崖 | Shader Graph，光照走 `CustomLighting.hlsl` |
| 深度 | 水面默认写入深度。焦散不写深度。天空盒不写深度，剔除关闭 |

## 每帧

```
初始化：生成波列 → 上传 GPU → 烘焙颜色 ramp → 拍岸边水深 → 打开平面反射
每相机：反射相机 → WaterFX（可空）→ 不透明物体 → 天空
        → 焦散乘到水下 → 海面（位移 + 折射 + 反射 + 泡沫）
LateUpdate：Burst Job 给已登记的浮力点算高度。本场景没有船
```

## 取舍

| 优点 | 限制 |
|------|------|
| 近岸泡沫、水深、倒影直接 | 远洋谱形不如 FFT 海洋 |
| 波条数少，顶点开销可控 | 平面反射要多画一遍场景 |
| 焦散不改水面网格 | 依赖深度纹理和不透明颜色纹理 |
