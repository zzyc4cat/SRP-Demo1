# 06.effect — 特效技术栈

总说明：[Assets/README.md](../../README.md)

五套透明特效共用 `Shaders/Library/EffectCommon.hlsl`（重映射、菲涅尔、流光 UV、软溶解、深度交界、六边形 SDF、哈希 / FBM 噪声）。场景里不再放说明文字。

| 效果 | 场景 | Shader |
|------|------|--------|
| 溶解流光 | `06.effect_DissolveFlow` | `ZZY/06.effect/DissolveFlow` |
| 写实火焰 | `06.effect_FireRealistic` | `ZZY/06.effect/FireRealistic` |
| 管道流水 | `06.effect_FlowPipe` | `FlowPipeGlass` + `FlowPipe` |
| 流光半透明 | `06.effect_FlowTranslucent` | `ZZY/06.effect/FlowTranslucent` |
| 能量护盾 | `06.effect_Shield` | `ZZY/06.effect/Shield` |

工具：`Assets/Editor/EffectDemoSetup.cs`（默认更新贴图 / 材质，不覆盖场景）

## 1. 溶解流光（`06.effect_DissolveFlow`）

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_DissolveFlow.unity` |
| Shader | `Shaders/06.effect_DissolveFlow.shader`（`ZZY/06.effect/DissolveFlow`） |
| 库 | `Shaders/Library/EffectCommon.hlsl` |
| 脚本 | `Scripts/DissolveFlowController.cs`（可选，驱动 `_DissolveAmount`） |

单 Pass，双面，`SrcAlpha OneMinusSrcAlpha`。默认不写深度，深度测试 LEqual。溶解前沿用软透明度过渡，只丢掉几乎看不见的像素。

| 段 | 技术 |
|----|------|
| 溶解 | `_NoiseMap` 的 R 和阈值比较。保留量用 `smoothstep` 做宽软淡出，并加 `fwidth` 抗锯齿，不再硬 `clip` 整条前沿 |
| 柔化 | `_EdgeSoft` 控透明度过渡宽度，`_EdgeWidth` 控亮边宽度。亮边向内外两侧衰减，半透明带上再铺一层光晕 |
| 自动 | `_Animate` 大于 0.5 时忽略手动进度，用正弦在 0~1 之间往复，速度是 `_AnimateSpeed` |
| 流光 | `EffectFlowUV` 按 `_FlowTiling`、`_FlowSpeed` 推动 `_FlowMap`，加到保留区域上 |
| 轮廓 | `EffectFresnel`，`_RimPower` 收边，`_RimIntensity` 控亮度 |
| 深度 | 默认不写深度，避免软溶解留下硬深度轮廓 |

| 优点 | 限制 |
|------|------|
| 溶解、亮边、流光、轮廓在一个 Pass 里 | 噪声贴图决定溶解形状，没有按高度逐层 |
| 可手动，也可自动往复 | 自动模式会盖掉 Dissolve Amount |

## 2. 写实火焰（`06.effect_FireRealistic`）

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_FireRealistic.unity` |
| Shader | `Shaders/06.effect_FireRealistic.shader`（`ZZY/06.effect/FireRealistic`） |
| 库 | `Shaders/Library/EffectCommon.hlsl`（`EffectFBM`） |
| 贴图 | 火焰序列帧、`EffectNoise` |

没有烟雾，也没有 VFX Graph。交叉的公告板用来增加体积。

单 Pass，双面，不写深度。混合是 `One OneMinusSrcAlpha`，片元输出预乘颜色，边缘不会出硬边。

| 段 | 技术 |
|----|------|
| 序列帧 | `_Columns` × `_Rows`（12×6）。`FireCellUV` 从左上起算格子，并略微内缩，避免过滤采到相邻帧 |
| 播放 | `SampleFlame` 采当前帧和下一帧，按帧内小数混合。`_FPS` 控速度，`_TimeOffset` 错开多个火焰 |
| 扭曲 | 两层噪声按 `_NoiseScale`、`_NoiseSpeed` 滚动。越靠近焰尖，`_Distort` 对 UV 的推动越强 |
| 外形 | `EffectFBM` 撕开两侧和顶部。`_SidePinch` 收窄两侧，`_VerticalScale` 压高度，`_SoftEdge` 软化遮罩 |
| 碎边 | `_WispStrength` 用同一层噪声打散序列帧的硬轮廓，主要作用在焰尖 |
| 颜色 | 暗部 `_TipColor`，中间 `_MidColor`，高亮 `_CoreColor`。底部再乘一层热度，根部更亮 |
| 顶点 | 上部顶点做轻微热浪偏移 |

| 优点 | 限制 |
|------|------|
| 序列帧提供真实火形，噪声只负责动和碎 | 帧数和分辨率决定细节上限 |
| 预乘混合，叠在场景上比较软 | 没有烟雾、火星和光照 |

## 3. 管道流水（`06.effect_FlowPipe`）

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_FlowPipe.unity` |
| 玻璃 | `Shaders/06.effect_FlowPipeGlass.shader`（`ZZY/06.effect/FlowPipeGlass`） |
| 液体 | `Shaders/06.effect_FlowPipe.shader`（`ZZY/06.effect/FlowPipe`） |
| 库 | `Shaders/Library/EffectCommon.hlsl` |
| 模型 | `FlowPipe.fbx` 的玻璃壳和液体子网格 |

两层网格叠在一起。玻璃在外，液体在内。

### 玻璃壳

双面，不写深度，`SrcAlpha OneMinusSrcAlpha`，叠在液体上面。

| 段 | 技术 |
|----|------|
| 边缘 | `1 - NdotV` 经 `smoothstep` 和 `_RimPower` 收成细边 |
| 高光 | 主光半角向量，`_SpecPower` 控锐度，再 `smoothstep` 去掉硬边 |
| 透明度 | 底色 Alpha 加边缘和高光，中间保持很低 |

### 液体

背面剔除，默认写入深度，让管壁内侧被液体挡住。混合 `SrcAlpha OneMinusSrcAlpha`。

| 段 | 技术 |
|----|------|
| 顶点浪 | UV.y 沿管长、UV.x 绕管。三层正弦沿法线做很小的径向起伏 |
| 流动 | `SoftFlow`：两层 `EffectFBM` 互相扭曲，主层沿管长拉长，次层更慢。宽 `smoothstep` 避免硬阈值锯齿 |
| 体积 | 正对视线的地方用 `_DeepColor` 加深，掠射处出 `_RimColor` |
| 光照 | 主光 Lambert 压在 0.75~1，避免液体被照黑 |

| 优点 | 限制 |
|------|------|
| 玻璃和液体分开，透明度可以各自调 | 液体写深度，会挡住管壁内侧 |
| 程序噪声，不依赖流动贴图动画 | 波纹是顶点正弦，不是流体模拟 |

## 4. 流光半透明（`06.effect_FlowTranslucent`）

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_FlowTranslucent.unity` |
| Shader | `Shaders/06.effect_FlowTranslucent.shader`（`ZZY/06.effect/FlowTranslucent`） |
| 库 | `Shaders/Library/EffectCommon.hlsl` |
| 贴图 | `EffectFlow` |

单 Pass，背面剔除，不写深度。混合 `SrcAlpha One`，轮廓和流光都往场景上加。

| 段 | 技术 |
|----|------|
| 轮廓 | `1 - NdotV` 在 `_RimMin` 和 `_RimMax` 之间 `smoothstep`。内部色 `_InnerColor` 过渡到 `_RimColor` |
| 流光坐标 | `EffectObjectFlowUV` 用物体空间位置，不跟模型 UV 走，所以身体正面不会出现镜像接缝 |
| 流光形状 | `_FlowMap` 按 `_FlowTiling`、`_FlowSpeed` 滚动，`_FlowPower` 把亮带收窄 |
| 透明度 | 轮廓、流光和 `_InnerAlpha` 相加。`_InnerAlpha` 避免身体中间完全镂空 |

| 优点 | 限制 |
|------|------|
| 流光贴在身体上，随物体移动 | 加色混合，叠在很亮的背景上会发白 |
| 不写深度，后面的物体仍可见 | 只有一层壳，没有厚度 |

## 5. 能量护盾（`06.effect_Shield`）

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_Shield.unity` |
| Shader | `Shaders/06.effect_Shield.shader`（`ZZY/06.effect/Shield`） |
| 库 | `Shaders/Library/EffectCommon.hlsl` |
| 网格 | `Models/ShieldHexSphere_Runtime.asset`。整球，局部半径约 1，物体缩放 (2,2,2)，世界半径约 2 |
| 材质 | `Materials/Shield.mat` |

护盾是透明双层网格：先画内侧面，再画外侧面。罩膜用 Base Color，和网格画在同一次片元里，膜在下、线在上。

| 层 | 技术 |
|----|------|
| 绘制顺序 | 背面 Pass：`SRPDefaultUnlit`，Cull Front。正面 Pass：`UniversalForward`，Cull Back。URP 每种 LightMode 只用第一个 Pass，所以两面不能共用同一个 LightMode，剔除也不能合成一个参数 |
| 深度 | 两面默认都不写深度，深度测试 LEqual。不写深度，正面才能透出背面网格；LEqual 让方块仍然挡住它后面的格子 |
| 六边形 | 每面 UV 是相对面心的尖顶六边形。`EffectHexSDF` 的外接圆半径 0.45，边到边用 `0.45 * √3 / 2`。边线宽度 `_HexLineWidth`，软边 `_HexLineSoft` |
| 格子身份 | 用面法线和 `EffectHexagonCenterWS` 取面心，不使用 UV2。UV2 不能一一对应六边形 |
| 罩膜 | `CompositeOverFilm` 把 Base Color 叠在网格下面。溶解掉的高度不再留膜 |
| 背面压暗 | 背面网格 RGB 乘 0.72，Alpha 不乘，避免正面线条把背面挖空 |
| 远近 | `ShieldDistanceFade` 只在整个护盾屏幕直径很小时压线。不用单格的 `fwidth`，否则远处的小面会被抹掉 |
| 轮廓 | 只在正面。按球面剪影算像素距离，粗细对齐六边形边线 |
| 边缘光 | 只在正面，用法线和视线的菲涅尔。背面若用外向法线会把整个半球点亮 |
| 交界 | `EffectDepthIntersection` 比较场景眼深度和片元眼深度。正反面都画，颜色走 `_EdgeColor`，强度为 0 时不出现 |
| 溶解 | `_DissolveAmount` 从 0 到 1。按面心的物体空间高度从顶端往下推进，整格边长一起缩小，收到 0 后该层消失。`_DissolveWidth` 是正在缩小的那一层厚度，边上加 `_DissolveEdgeColor` |
| 流光 | 两团光关于球心点对称：方向 `d` 和 `-d`。轨道是 `yaw = a + 小幅整数倍正弦`，相位 0 和 1 重合，偏航始终向前，长时间用 `WrapTime` 把时间和速度折进 0~1。光斑约 28 度，和 180 度对点不会相交。亮的是整格内部，不降低边线 Alpha |
| 时间 | 不把原始 `_Time.y` 送进噪声或相位，避免编辑器长时间运行后精度丢失、流光突然跳变 |

相机需要深度纹理，交界亮缝才有场景深度可比。

```
顶点：世界位置、法线、球心
片元（正反面共用）：
  面心高度 → 溶解缩放
  六边形 SDF → 边线、填充、整格内部
  球心对称的两团流光 → 只加在格子内部
  正面额外：剪影描边、菲涅尔
  正反面：深度交界
  罩膜叠在网格下面
背面再把 RGB 压暗
```

| 优点 | 限制 |
|------|------|
| 两面网格、膜、线的层级稳定 | 只有两个 Pass，不能再加第三个同 LightMode 的层 |
| 溶解和流光都按整格六边形走 | 溶解是高度带，不是噪声碎片 |
| 流光首尾相接，不会越跑越跳 | 两团光永远在球的两边，不能靠到一起 |
