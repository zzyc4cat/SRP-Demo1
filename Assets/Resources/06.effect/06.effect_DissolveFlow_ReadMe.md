## 技术栈

单 Pass，双面，`SrcAlpha OneMinusSrcAlpha`。默认写入深度，深度测试 LEqual，溶解掉的部分用 `clip` 去掉，后面的物体能透出来。

| 段 | 技术 |
|----|------|
| 溶解 | `_NoiseMap` 的 R 和阈值比较。`EffectDissolve` 输出保留量和前沿宽度。`_DissolveAmount` 为 0 时完整，为 1 时按噪声全部溶解 |
| 自动 | `_Animate` 大于 0.5 时忽略手动进度，用正弦在 0~1 之间往复，速度是 `_AnimateSpeed` |
| 亮边 | 前沿 `edge` 把颜色替换成 `_EdgeColor * _EdgeIntensity` |
| 流光 | `EffectFlowUV` 按 `_FlowTiling`、`_FlowSpeed` 推动 `_FlowMap`，加到保留区域上 |
| 轮廓 | `EffectFresnel`，`_RimPower` 收边，`_RimIntensity` 控亮度 |

## 取舍

| 优点 | 限制 |
|------|------|
| 溶解、亮边、流光、轮廓在一个 Pass 里 | 噪声贴图决定溶解形状，没有按高度逐层 |
| 可手动，也可自动往复 | 自动模式会盖掉 Dissolve Amount |
