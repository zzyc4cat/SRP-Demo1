## 技术栈

两层网格叠在一起。玻璃在外，液体在内。

### 玻璃壳

双面，不写深度，`SrcAlpha OneMinusSrcAlpha`，叠在液体上面。

| 段 | 技术 |
|----|------|
| 边缘 | `1 - NdotV` 经 `smoothstep` 和 `_RimPower` 收成细边 |
| 高光 | 主光半角向量，`_SpecPower` 控锐度，再 `smoothstep` 去掉硬边 |
| 透明度 | 底色 Alpha 加边缘和高光，中间保持很低 |

### 液体

背面剔除，默认写入深度，让管壁内侧被液体挡住。混合 `SrcAlpha OneMinusSrcAlpha`。

| 段 | 技术 |
|----|------|
| 顶点浪 | UV.y 沿管长、UV.x 绕管。三层正弦沿法线做很小的径向起伏 |
| 流动 | `SoftFlow`：两层 `EffectFBM` 互相扭曲，主层沿管长拉长，次层更慢。宽 `smoothstep` 避免硬阈值锯齿 |
| 体积 | 正对视线的地方用 `_DeepColor` 加深，掠射处出 `_RimColor` |
| 光照 | 主光 Lambert 压在 0.75~1，避免液体被照黑 |

## 取舍

| 优点 | 限制 |
|------|------|
| 玻璃和液体分开，透明度可以各自调 | 液体写深度，会挡住管壁内侧 |
| 程序噪声，不依赖流动贴图动画 | 波纹是顶点正弦，不是流体模拟 |
