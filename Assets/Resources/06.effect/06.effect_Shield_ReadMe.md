# 06.effect_Shield — 六边形能量护盾

总说明：[Assets/README.md](../../README.md)

| 项 | 说明 |
|----|------|
| 场景 | `Assets/Scenes/06.effect_Shield.unity` |
| Shader | `Shaders/06.effect_Shield.shader`（`ZZY/06.effect/Shield`） |
| 库 | `Shaders/Library/EffectCommon.hlsl` |
| 网格 | `Models/ShieldHexSphere_Runtime.asset`。整球，局部半径约 1，物体缩放 (2,2,2)，世界半径约 2 |
| 材质 | `Materials/Shield.mat` |

护盾是透明双层网格：先画内侧面，再画外侧面。罩膜用 Base Color，和网格画在同一次片元里，膜在下、线在上。

---

## 技术栈

| 层 | 技术 |
|----|------|
| 绘制顺序 | 背面 Pass：`SRPDefaultUnlit`，Cull Front。正面 Pass：`UniversalForward`，Cull Back。URP 每种 LightMode 只用第一个 Pass，所以两面不能共用同一个 LightMode，剔除也不能合成一个参数 |
| 深度 | 两面默认都不写深度，深度测试 LEqual。不写深度，正面才能透出背面网格；LEqual 让方块仍然挡住它后面的格子 |
| 六边形 | 每面 UV 是相对面心的尖顶六边形。`EffectHexSDF` 的外接圆半径 0.45，边到边用 `0.45 * √3 / 2`。边线宽度 `_HexLineWidth`，软边 `_HexLineSoft` |
| 格子身份 | 用面法线和 `EffectHexagonCenterWS` 取面心，不使用 UV2。UV2 不能一一对应六边形 |
| 罩膜 | `CompositeOverFilm` 把 Base Color 叠在网格下面。溶解掉的高度不再留膜 |
| 背面压暗 | 背面网格 RGB 乘 0.72，Alpha 不乘，避免正面线条把背面挖空 |
| 远近 | `ShieldDistanceFade` 只在整个护盾屏幕直径很小时压线。不用单格的 `fwidth`，否则远处的小面会被抹掉 |
| 轮廓 | 只在正面。按球面剪影算像素距离，粗细对齐六边形边线 |
| 边缘光 | 只在正面，用法线和视线的菲涅尔。背面若用外向法线会把整个半球点亮 |
| 交界 | `EffectDepthIntersection` 比较场景眼深度和片元眼深度。正反面都画，颜色走 `_EdgeColor`，强度为 0 时不出现 |
| 溶解 | `_DissolveAmount` 从 0 到 1。按面心的物体空间高度从顶端往下推进，整格边长一起缩小，收到 0 后该层消失。`_DissolveWidth` 是正在缩小的那一层厚度，边上加 `_DissolveEdgeColor` |
| 流光 | 两团光关于球心点对称：方向 `d` 和 `-d`。轨道是 `yaw = a + 小幅整数倍正弦`，相位 0 和 1 重合，偏航始终向前，长时间用 `WrapTime` 把时间和速度折进 0~1。光斑约 28 度，和 180 度对点不会相交。亮的是整格内部，不降低边线 Alpha |
| 时间 | 不把原始 `_Time.y` 送进噪声或相位，避免编辑器长时间运行后精度丢失、流光突然跳变 |

相机需要深度纹理，交界亮缝才有场景深度可比。

## 数据流

```
顶点：世界位置、法线、球心
片元（正反面共用）：
  面心高度 → 溶解缩放
  六边形 SDF → 边线、填充、整格内部
  球心对称的两团流光 → 只加在格子内部
  正面额外：剪影描边、菲涅尔
  正反面：深度交界
  罩膜叠在网格下面
背面再把 RGB 压暗
```

## 取舍

| 优点 | 限制 |
|------|------|
| 两面网格、膜、线的层级稳定 | 只有两个 Pass，不能再加第三个同 LightMode 的层 |
| 溶解和流光都按整格六边形走 | 溶解是高度带，不是噪声碎片 |
| 流光首尾相接，不会越跑越跳 | 两团光永远在球的两边，不能靠到一起 |
