没有烟雾，也没有 VFX Graph。交叉的公告板用来增加体积。

---

## 技术栈

单 Pass，双面，不写深度。混合是 `One OneMinusSrcAlpha`，片元输出预乘颜色，边缘不会出硬边。

| 段 | 技术 |
|----|------|
| 序列帧 | `_Columns` × `_Rows`（12×6）。`FireCellUV` 从左上起算格子，并略微内缩，避免过滤采到相邻帧 |
| 播放 | `SampleFlame` 采当前帧和下一帧，按帧内小数混合。`_FPS` 控速度，`_TimeOffset` 错开多个火焰 |
| 扭曲 | 两层噪声按 `_NoiseScale`、`_NoiseSpeed` 滚动。越靠近焰尖，`_Distort` 对 UV 的推动越强 |
| 外形 | `EffectFBM` 撕开两侧和顶部。`_SidePinch` 收窄两侧，`_VerticalScale` 压高度，`_SoftEdge` 软化遮罩 |
| 碎边 | `_WispStrength` 用同一层噪声打散序列帧的硬轮廓，主要作用在焰尖 |
| 颜色 | 暗部 `_TipColor`，中间 `_MidColor`，高亮 `_CoreColor`。底部再乘一层热度，根部更亮 |
| 顶点 | 上部顶点做轻微热浪偏移 |

## 取舍

| 优点 | 限制 |
|------|------|
| 序列帧提供真实火形，噪声只负责动和碎 | 帧数和分辨率决定细节上限 |
| 预乘混合，叠在场景上比较软 | 没有烟雾、火星和光照 |
