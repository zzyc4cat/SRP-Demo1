## 技术栈

单 Pass，背面剔除，不写深度。混合 `SrcAlpha One`，轮廓和流光都往场景上加。

| 段 | 技术 |
|----|------|
| 轮廓 | `1 - NdotV` 在 `_RimMin` 和 `_RimMax` 之间 `smoothstep`。内部色 `_InnerColor` 过渡到 `_RimColor` |
| 流光坐标 | `EffectObjectFlowUV` 用物体空间位置，不跟模型 UV 走，所以身体正面不会出现镜像接缝 |
| 流光形状 | `_FlowMap` 按 `_FlowTiling`、`_FlowSpeed` 滚动，`_FlowPower` 把亮带收窄 |
| 透明度 | 轮廓、流光和 `_InnerAlpha` 相加。`_InnerAlpha` 避免身体中间完全镂空 |

## 取舍

| 优点 | 限制 |
|------|------|
| 流光贴在身体上，随物体移动 | 加色混合，叠在很亮的背景上会发白 |
| 不写深度，后面的物体仍可见 | 只有一层壳，没有厚度 |
