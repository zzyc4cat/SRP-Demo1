## 技术栈

| 阶段 | 技术 |
|------|------|
| 能量谱 | JONSWAP，加 TMA 有限水深修正。局地风浪和涌浪两套谱叠加 |
| 方向 | Donelan-Banner / Cosine2s 展宽 |
| 色散 | `ω(k) = √(gk tanh(kd))` |
| 变换 | Stockham GPU IFFT。先横后纵，ping-pong |
| 级联 | 三个 `LengthScale`（约 250 / 17 / 5）。波数环带互斥，避免同一频率画两次 |
| 白沫 | Tessendorf Jacobian：`J = (1+λDxx)(1+λDzz) − (λDxz)²`。帧间累积，再加波峰高度和四方连续噪声 |
| 表面 | 顶点采三频带位移。片元用导数重建法线，按场景深度混合水色和 Beer 吸收，Fresnel 反射天空，Blinn 高光，次表面，主光阴影 |
| 深度 | 海面默认不写深度，深度测试 LEqual，便于和透明物、深度后处理配合 |

## 每帧数据流

```
参数变更时：Box-Muller 高斯噪声 + InitialSpectrum → H0 / WavesData × 3
每帧：TimeDependentSpectrum 推进相位，打包 Dx、Dy、导数
      → Stockham IFFT × 4 路
      → Merger 写出 Displacement、Derivatives、Turbulence
      → 材质采样，顶点位移，片元着色
```

## 关键参数

| 参数 | 含义 |
|------|------|
| `fftPow` | 分辨率 N = 2^fftPow。8 对应 256 |
| `lengthScale0/1/2` | 大浪、中浪、细浪的周期尺度 |
| `lambda` | 水平挤压。越大越容易折叠，白沫也越多 |
| `FoamBias` | 三频带 Jacobian 求和后的白沫阈值，大约 2.85 |
| `CrestFoam` | 浪尖额外白沫 |
| `_FoamNoise` | 絮状调制，贴图需要四方连续 |

## 取舍

| 优点 | 限制 |
|------|------|
| 谱方法细节多，计算在 GPU | 需要桌面级 Compute |
| 三级联减轻单一平铺感 | 贴片仍然周期重复 |
| 白沫和几何折叠一致 | 没有浮力；反射是探针级，不是平面反射 |
