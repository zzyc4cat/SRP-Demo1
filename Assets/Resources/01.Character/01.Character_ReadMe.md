# 01.Character — 卡通角色

|----|------|
| 场景 | `Assets/Scenes/01.Character.unity` |

---

## 技术栈

| 层 | 技术 |
|----|------|
| 管线 | URP Forward。三个 Pass，深度写入默认开启，深度测试默认 LEqual |
| 身体光照 | 半 Lambert 经 `smoothstep` 柔化后乘 lightmap.g，再按 lightmap.a 选 Ramp 行 |
| 昼夜 | `_dayAndNight` 把 Ramp 采样 V 推到下半张 |
| 脸部 | `_genshinShader` 大于 0.5 时正面改走 `ShadeFace`：左右翻转采样 FaceLightmap，用主光在 XZ 上的投影和 SDF 阈值做硬边。背面只做身体着色 |
| 金属 | lightmap.r 高值区采样 `_metalMap`，颜色由 `_metalMapColor` 调制 |
| 高光 | Blinn-Phong，受亮面遮罩限制，避免暗面出高光 |
| 边缘光 | 阈值化菲涅尔，`_fresnel` 控范围，`_edgeLight` 控强度 |
| 自发光 | `_diffuse` 的 Alpha 可做裁剪或发光遮罩；发光按 `_flicker` 正弦闪 |
| 法线 | `_bumpMap` 切线空间，`_bumpScale` 控强度 |
| 描边 | `GenshinOutline`（`SRPDefaultUnlit`）沿法线外扩，按 lightmap.a 选五档描边色 |

## Pass

| Pass | LightMode | 作用 |
|------|-----------|------|
| GenshinForward | `UniversalForward` | 正面，Cull Back，采样 UV0 |
| GenshinBackface | `UniversalForwardOnly` | 背面，Cull Front，采样 UV1 |
| GenshinOutline | `SRPDefaultUnlit` | 反向扩张描边 |

URP 对每种 LightMode 只画该 Shader 的第一个 Pass，所以正面、背面、描边必须落在三个不同的 LightMode 上。

## 贴图

| 属性 | 用途 |
|------|------|
| `_diffuse` | 固有色。Alpha 由 `_diffuseA` 决定是裁剪还是自发光 |
| `_lightmap` | 身体：AO / 高光 / 金属 / 材质 ID。脸部：SDF |
| `_bumpMap` | 切线空间法线 |
| `_ramp` | 阴影色带。上半白天，下半夜晚 |
| `_metalMap` | 金属反射调制 |

## 取舍

| 优点 | 限制 |
|------|------|
| 明暗、金属、描边都按贴图分区 | 不是能量守恒 PBR |
| 脸和身体共用一个 Shader，用开关切换 | 依赖专用 Lightmap 和 Ramp |
| 双面 UV 分开，适合发卡、裙摆 | 描边宽度对法线质量敏感 |
