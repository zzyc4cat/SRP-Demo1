## 技术栈

glTF 2.0 Metallic-Roughness。Cook-Torrance：GGX 法线分布、Smith 几何项、Schlick 菲涅尔。介质 F0 为 0.04，金属把 F0 换成基础色。

| 段 | 技术 |
|----|------|
| 表面 | `_BaseMap` 的 RGB × `_BaseColorFactor`。金属度在金属粗糙度贴图的 B，粗糙度在 G。遮蔽在 R，自发光单独一张图 |
| 直接光 | `GltfShadeDirectLight`：漫反射乘 `(1 - F)` 和 `(1 - transmission)`，高光为 `D * G * F / (4 NdotV NdotL)` |
| 环境 | `GltfShadeEnvironment`：辐照度漫反射加按粗糙度选 mip 的预滤波反射 |
| 法线 | 切线空间法线贴图，`_BumpScale` 控强度 |
| 透射 | `GltfShadeTransmission`。按折射率偏移屏幕 UV，采样不透明颜色，再乘体积衰减 `(attenuationColor, attenuationDistance, thickness)` |
| 调试 | `_DebugMode` 可单独输出基础色、金属、粗糙度、法线、遮蔽、D、F 等项 |
| 深度 | 不透明 Forward、ShadowCaster、DepthOnly 默认写深度，测试 LEqual。只写深度的 Pass 默认 `ColorMask` 为 0。透射 Pass 不写深度，混合 `One OneMinusSrcAlpha`，叠在场景上面 |

## Pass

| Shader | Pass | 作用 |
|--------|------|------|
| glTFPBR | ForwardLit | 主着色 |
| glTFPBR | ShadowCaster | 阴影，不输出颜色 |
| glTFPBR | DepthOnly | 深度，不输出颜色 |
| glTFPBRTransmission | ForwardTransmission | 折射和体积色，不写深度 |

## 场景里的测试

| 组 | 在看什么 |
|----|----------|
| 金属 / 粗糙度网格 | 金属度从左到右 0→1，粗糙度从上到下 0→1 |
| 高光 | 高光形状、强度、菲涅尔。Debug 可把 D 和 F 拆开 |
| 法线 | 切线空间法线、BumpScale、一块镜面参照 |
| 透射 | 透射和粗糙度一起变，体积衰减，屏幕空间折射 |

## 取舍

| 优点 | 限制 |
|------|------|
| 和 glTF 贴图通道一致，方便对照 | 不是完整的多散射或色散玻璃 |
| 透射和金属体分开，深度不会互相挡住 | 折射采样的是不透明颜色，看不到透明物后面的透明物 |
