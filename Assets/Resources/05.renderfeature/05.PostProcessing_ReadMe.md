## 技术栈

全屏三角形由 `PPVert` 画出。后处理 Pass 默认不写深度，深度测试为 Always，剔除关闭。Bloom 分层遮罩的 `ColorMask` 默认只写 RGB。

顺序固定为：

```
CameraColor
  → Copy
  → HeightFog（世界高度 Y，贴地浓）
  → DepthFog（相机距离；end ≤ start 时用指数，否则线性）
  → DepthOfField（焦点 + 近处 / 远处过渡）
  → Bloom（只提取 layerMask 里的物体）
  → Outline（深度和颜色边缘）
  → ChromaticAberration（径向 RGB 分离）
  → Tonemapping（曝光、对比、饱和）
  → 写回 CameraColor
```

| Shader | 作用 |
|--------|------|
| `ZZY/05.renderfeature/Copy` | 拷贝源颜色 |
| `ZZY/05.renderfeature/HeightFog` | 高度雾 |
| `ZZY/05.renderfeature/DepthFog` | 距离雾 |
| `ZZY/05.renderfeature/DepthOfField` | 景深 |
| `ZZY/05.renderfeature/Bloom` | 阈值、降采样、上采样、合成。上采样里有一条 `Blend One One` |
| `ZZY/05.renderfeature/BloomLayerMask` | 分层遮罩 |
| `ZZY/05.renderfeature/BloomMaskMultiply` | 遮罩相乘 |
| `ZZY/05.renderfeature/Outline` | 描边 |
| `ZZY/05.renderfeature/ChromaticAberration` | 色差 |
| `ZZY/05.renderfeature/Tonemapping` | 色调映射 |

## Layer Bloom

只有 `bloom.layerMask` 里的物体参与辉光。

1. 单独的 `RenderTexture`（自带深度）清成黑色。
2. `DrawRenderers` 按 Layer 用物体自己的材质重画一遍。
3. 无材质 `Blit` 拷到临时 RT，再做 Prefilter 和金字塔降采样。
4. 上采样用模糊结果加 Additive，避免临时 RT 绑 `_SourceTex2` 失败。
5. 拷回真实 RT，`Material.SetTexture` 后和场景合成。

测试约定：发光物体放在 `Bloom` Layer，Manager 的 `layerMask` 只勾选这一层。

## 取舍

| 优点 | 限制 |
|------|------|
| 每步一个 Shader，可单独开关 | 要自己挂 Feature 和场景里的 Manager |
| Bloom 可以按 Layer 隔离 | 多一次指定 Layer 的重绘 |
| 不依赖 Volume 栈 | 不是完整的影视后期套件 |
